# ShaneeNails

Plataforma web para gestión de citas de nail art independiente.

## Funcionalidades

- Registro e inicio de sesión de clientas
- Galería de trabajos con filtros por servicio y etiqueta
- Agendamiento de citas en 3 pasos con calendario interactivo
- Sistema de cotizaciones personalizadas
- Portal de la clienta con historial de citas
- Panel de administración completo
- Notificaciones por email automáticas

## Tecnologías

- PHP 8.4
- MySQL
- HTML, CSS, JavaScript
- PHPMailer
- Composer

## Instalación local

1. Clona el repositorio en `htdocs` de XAMPP
2. Crea la base de datos `shaneenails` en phpMyAdmin
3. Importa el archivo `database.sql`
4. Copia `.env.example` y renómbralo `.env`
5. Rellena las credenciales en `.env`
6. Ejecuta `composer install`
7. Abre `http://localhost/shaneenails`

## Credenciales de prueba

- **Admin:** admin@shaneenails.com / password
- **Cliente:** registrarse desde la web
